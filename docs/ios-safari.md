# iPhone Safari acceptance criteria

- [ ] No Flash plugin or external app required.
- [ ] Portrait and landscape preserve original scene aspect ratio.
- [ ] Safe areas do not cover controls or interactions.
- [ ] One-finger touch works without hover dependencies or accidental page scrolling.
- [ ] First gesture unlocks audio; iOS silent mode behavior documented.
- [ ] Pause/background/foreground preserves event progress.
- [ ] Scene and scare-event assets preloaded without visible stalls.
- [ ] Memory/texture usage acceptable on a physical iPhone.
- [ ] Original behavior comparison signed off with recorded evidence.
